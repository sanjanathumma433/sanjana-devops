# Loan Approval System

## Project Description

A Flask-based web application that checks loan eligibility based on the applicant's age, credit score, salary, employment, EMI, and other financial details.

## Features

- Age eligibility check
- Credit score verification
- Salary verification
- Secured and unsecured loan checking
- EMI calculation
- Collateral verification
- Loan approval and rejection

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- GitHub
- Jenkins
